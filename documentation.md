# Élan Fitness — Salle de Sport à Casablanca 🏋️‍♂️
Bienvenue dans le projet **Élan Fitness**, un site web statique développé pour présenter une salle de sport à Casablanca. Ce projet met en pratique la structuration sémantique HTML5, la gestion du CSS, ainsi qu'une méthodologie de travail organisée avec Trello, Git et GitHub.

---

## 📁 Structure du Projet

```text
.
├── img/                  # Images et icônes du site (musculation...)
├── index.html            # Page d'accueil principale
├── propos.html           # Page "À propos" 
├── programms.html        # Page des programmes et formules d'abonnement
├── contact.html          # Page de contact avec formulaire interactif
├── documentation.md      # Documentation technique sur les bases CSS
└── README.md             # Présentation générale du projet et suivi des tâches
```

## 🛠️ Étapes de Réalisation du Projet

1. **Planification Trello :** Organisation des cartes pour structurer les priorités et suivre l'avancement.
2. **Initialisation du Repository GitHub :** Création du dépôt distant et suivi des modifications avec Git.
3. **Découpage des Pages HTML :** Structuration sémantique des différentes pages du site (`header`, `nav`, `main`, `section`, `footer`).
4. **Documentation CSS :** Explication des concepts fondamentaux du CSS appliqués au projet .

* **HTML5** : Structure sémantique et accessibilité.

* **Trello** : Gestion et suivi du projet.
